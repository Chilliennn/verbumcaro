# VerbumCaro

Catholic Bible reader built with React, TypeScript and Vite.

## Stage 1

Implemented:

- React + TypeScript + Vite
- Static Bible repository
- Two-panel parallel reading
- Passage picker
- Translation selector
- Search/reference input
- Light/dark mode
- Heading toggle
- Parallel toggle
- Verse synchronization
- Local preference persistence
- Responsive layout
- URL state for both panels
